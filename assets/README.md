# 视频导演头像 / Avatar

`avatar.png` 是为本智能体原创生成的虚构人物透明背景职业肖像。与同系列另一角色保持协调，保留清楚的人脸、头肩构图和明暗界面可用的轮廓。由内置 imagegen 生成，不描绘特定真人，不含姓名、商标或水印；未复制上游项目的人像。

The original AI-generated portrait depicts a fictional professional, with a transparent background and a head-and-shoulders composition for both light and dark interfaces. It is part of a coordinated pair, not a photograph of a specific real person or an upstream asset.

该图片随 Git 源码分发；`agent.json` 以相对路径引用。`generationPolicy: manual` 表示使用已提供图片，安装无需再次生成头像；“导”字和绿色仅作图片不可用时的回落。用户可在平台中替换头像。

The seed references this bundled image through a relative path. The manual generation policy uses the supplied image without a new generation request during installation; the character/color remain fallbacks. Users can replace the image in DesireCore.
